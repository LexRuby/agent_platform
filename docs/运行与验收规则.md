# 运行与验收规则

## 线上服务可见性

1. 本地执行环境可能无法访问公网，`curl`、端口探测或本地进程列表失败，只能说明当前环境不可见，不能据此判断线上服务已停止或异常。
2. 线上验收以用户提供的公网 URL、用户浏览器实际状态和服务端可观测证据为准。用户确认线上仍在使用时，不得停止、重启或替换线上服务。
3. 未经用户明确授权，不执行线上停机、部署、回滚或批量清理操作。需要释放本地内存时，只处理本地测试进程和本地临时任务。

## 权限问题排查

遇到“回复失败”“会话准备失败”或工具不可用时，先区分四类状态：

- 当前执行环境无公网访问权限；
- 用户账号没有模型凭证或智能体权限；
- 会话正在等待用户确认；
- 远端服务实际不可用。

不能把第一类直接推断为第四类，也不能在未确认原因时修改线上配置。

## 验收边界

验收前只运行必要的本地测试和低并发真实调用；真实调用使用临时会话并清理。线上已有会话和用户正在使用的服务保持不变。
